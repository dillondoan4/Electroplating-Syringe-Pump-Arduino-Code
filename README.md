# Electroplating-Syringe-Pump-Arduino-Code
This code is for the Arduino Uno. It controls a NEMA 17 Stepper Motor, which turns a lead screw to push or retract the syringe. It has three functions: eject, retract, and stop. The speed can be controlled by the potentiometer connected to the Arduino Uno or by entering a value into the serial monitor. To switch controls between potentiometer and the serial monitor value, enter pot to switch to the potentiometer or enter a number to set the step delay. Lower numbers mean faster because of a lower step delay. Pressing the eject, retract, or stop buttons connected to Arduino Uno controls the function.
